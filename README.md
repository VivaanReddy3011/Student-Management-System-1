## 🚀 Getting Started

### Prerequisites

* Node.js (v18+ recommended)
* npm

### Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/student-management-system.git
cd student-management-system
```

2. Install dependencies

```bash
# Backend
cd backend
npm install

# Frontend
cd ../frontend
npm install
```

### Run the Application

Start the backend:

```bash
cd backend
npm run dev
```

Start the frontend (in a new terminal):

```bash
cd frontend
npm run dev
```

### Local URLs

| Service     | URL                   |
| ----------- | --------------------- |
| Frontend    | http://localhost:5173 |
| Backend API | http://localhost:3000 |

## 📖 About

The Student Management System is a full-stack web application built to practice modern web development with React and Express.js. It allows users to perform CRUD operations on student records through a clean RESTful API while following a modular backend architecture.

This project focuses on understanding frontend-backend communication, REST APIs, and building scalable applications using industry-inspired practices.

## ✨ Key Features

* User registration and login
* Create, read, update, and delete student records
* RESTful API built with Express.js
* Modular MVC-inspired backend architecture
* React frontend with controlled forms and hooks
* Real-time UI updates using the Fetch API

## 🎯 Learning Goals

This project was built to strengthen my understanding of:

* React fundamentals and component-based development
* Building REST APIs with Express.js
* Frontend-backend communication
* CRUD application development
* Routing and controller separation
* State management using React Hooks
* Writing clean, maintainable, and modular code
